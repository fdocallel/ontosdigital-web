La figura necesita WebGL. Puedes visitar el patio 2D.
La figura está en reposo.

Abrir el patio 2D
Arrastra para girar · pellizca o usa la rueda para acercarte

Puedes mirar por delante, detrás, arriba y abajo. Al arrastrar se detiene el giro automático. «Vida» activa la respiración y los pequeños gestos; apágala para observarlo quieto. «Solo figura» llena la pantalla con ONTOS; vuelve con el botón superior o Escape.

Con el lienzo enfocado: flechas para girar, + y − para cambiar el tamaño, Inicio para recuperar la vista y H para saludar. Centrar recupera también la pose de pie.
